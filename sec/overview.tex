\section{Informal Overview of the Solution}

\subsection{\OurLang: A Data-Transparent Programming Language}
\label{sec:overview:our-lang}

We implement the abstract framework outlined above in a programming language called \OurLang, a pure
functional language with a runtime implementing conjugate dependency operators. From the programmer's
perspective the language is unremarkable. The distinguishing feature of the language is a special
semantics that interprets a program not as a plain output but as an output with a built-in query engine
supporting the transparency features shown above. The author of a visualisation just expresses their chart as
a pure function of the inputs, via a set of data types for common visualisations; a d3.js front end
automatically enriches the rendered outputs with support for visual selection and various selection-based
queries.

We set out the formal graph framework in \secref{conjugate}, and then show how
our core language \OurLang implements that abstract framework in \secref{core}.
