\subsection{Preliminaries}

Meta-variables $x, y$ range over a countably infinite set of \emph{variables} plus a distinguished variable,
written $\varAnon$, called the \emph{anonymous} variable.

For any constructor $c$ we write $\datatype{\Delta}{c}$ for the corresponding datatype.
