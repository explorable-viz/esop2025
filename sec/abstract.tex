\begin{abstract}
   Galois connections between Boolean algebras offer an appealing formal framework for bidirectional dynamic
   program slicing, providing an elegant characterisation of the relationship between input and output
   resources in terms of demand and sufficiency. The upper adjoint (forward slicing) picks out all the outputs
   for which a given set of inputs are sufficient, whereas the lower adjoint (backward slicing) picks out the
   specific inputs demanded by a set of outputs. \citeauthor{perera22} showed how the De Morgan dual of these
   operators can be used to pick out \emph{related outputs}, namely all other outputs whose demand overlaps
   with a given set of outputs. However Galois slicing implementations to date have relied on a sequential
   execution record, or \emph{trace}, to compute the bidirectional analysis, making the approach unable to
   exploit the independence information that makes slicing useful in the first place and rendering it too slow
   for interactive applications.

   In this paper we present a new implementation technique for Galois slicing based on dynamic dependence
   graphs (DDGs). The approach decomposes the slicing procedure into steps: evaluating a program to a DDG, and
   then running forwards and backwards slicing algorithms over the graph. While DDGs have long been used for
   program slicing, in the Galois connection setting a number of other interesting properties arise. Backward
   slicing is the usual reachability analysis, but extensionally forward slicing is simply the De Morgan dual
   of backward slicing on the opposite graph, leading to an easy implementation of the upper adjoint in terms
   of the lower. Since this naive implementation can be inefficient (in the worst case taking time
   proportional to the size of the graph), we also give a direct implementation of forward slicing over a DDG
   and show that it too is on average much faster than the trace-based approach.

   Our slicing algorithms are neutral with respect to any intensional information associated with the DDG,
   presenting further opportunities for performance improvements. In particular, the Galois connections are
   invariant under any graph transformation that preserves the ``I/O relation'' of the DDG; so for example any
   transformation that elides internal nodes but preserve connectivity will produce an extensionally
   equivalent (but faster) analysis. We conjecture that this might be used to selectively trade intensional
   information for additional performance improvements.
