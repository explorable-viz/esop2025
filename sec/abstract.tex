\begin{abstract}
   Galois connections between Boolean algebras offer an appealing formal framework for bidirectional dynamic
   program slicing, providing an elegant characterisation of the relationship between input and output
   resources in terms of demand and sufficiency. The upper adjoint (forward slicing) picks out all the outputs
   for which a given set of inputs are sufficient; the lower adjoint (backward slicing) picks out the specific
   inputs demanded by a set of outputs. \citeauthor{perera22} showed how such a Galois connection could be
   composed with its own De Morgan dual to calculate \emph{related outputs}, namely outputs which compete for
   inputs with other outputs. However implementations of this technique to date have relied on a sequential
   execution record, or \emph{trace}, to compute the bidirectional analysis, making the approach impractical
   for interactive applications where response time is at a premium.

   In this paper we present a new implementation technique for Galois slicing based on dynamic dependence
   graphs (DDGs). While DDGs have long been used for program slicing outside of the Galois connection setting,
   we show that. Backward slicing as an easy reachability analysis in the graphical setting, but we show that
   a number of other interesting properties arise. Extensionally, forward slicing over a DDG is simply the De
   Morgan dual of backward slicing on the opposite graph, leading to an easy (although inefficient)
   implementation of the adjoint analysis. We also give a more direct implementation of forward slicing over a
   DDG and show that it too is on average much faster than the trace-based approach.
