\begin{abstract}
   Galois connections have been shown to offer an appealing ``resource interpretation'' for bidirectional
   dynamic program slicing, where the upper adjoint (forward slicing), for a given set of input resources,
   determines all the outputs that can be computed using only those inputs, and the lower adjoint (backward
   slicing) determines the input resources demanded by a set of outputs. \citeauthor{perera22} in particular
   showed how this perspective could be combined with a De Morgan dual [...]. However, existing
   implementations of this technique rely on a sequential execution record, or \emph{trace}, along which to
   compute the analysis, making the approach impractical for highly interactive applications.

   In this paper we present a new implementation technique for Galois slicing based on dependence graphs.
