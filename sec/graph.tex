$G$ ranges over \emph{dependency graphs} $(V, E)$ where $V$ is a set of \emph{addresses} which serve as
vertices.  Addresses include a distinguished address $\addrNull$ called the \emph{null} address.

\begin{definition}
   For any $G = (V, E)$, any $V' \subseteq V$ and any $\upalpha \notin V$, define $\mkAddr{G}{V'}{\upalpha} = (V \cup \set{\upalpha}, E \cup (V' \times \set{\upalpha}))$.
\end{definition}
