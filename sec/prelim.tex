The (countably infinite) set $\Var$ include a distinguished variable $\varAnon$ called the \emph{anonymous}
variable. The set of foreign function names $\Foreign$ is a finite subset of $\Var$. The language is also
parameterised on a map $\Sigma$ that assigns to every $f \in \Foreign$ a signature $(\seq{A}, B)$.

For any constructor $c$ we write $\datatype{\Delta}{c}$ for the corresponding datatype.

For some purposes, the annotations are irrelevant, and so we can set $\Ann{A}$ to be the unit lattice, in
which case we highlight a term in bold, and elide the annotations $\upalpha$ from the syntax. We call such
terms \emph{raw} terms.
