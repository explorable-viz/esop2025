\section{Background}
\label{sec:background}
In the Fluid language, both values and expressions can be annotated with what are termed selection states $\upalpha \in \Ann{A}$, with the set of possible annotations $\Ann{A}$ forming a lattice. For some purposes, the annotations are irrelevant, and so we can set $\Ann{A}$ to be the unit lattice, in which case we highlight a term in bold, and elide the annotations $\upalpha$ from the syntax. We call terms annotated with the unit \emph{raw} terms.
