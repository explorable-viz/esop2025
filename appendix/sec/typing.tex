\subsection{Core language typing}

Eliminators are polymorphic in the type of the object they return, which we call the continuation type;
typically an eliminator returns another eliminator or an expression. We use $\elimTyArrow$ in the syntax of
both eliminators and eliminator types; the meaning should be clear from context. Well-typed eliminators are
never partial.
