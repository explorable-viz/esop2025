\begin{definition}[Finite map notation]
   Write $\seq{\bind{z}{w}}$ to denote a sequence of pairs $\seqRange{\bind{z_1}{w_1}}{\bind{z_n}{w_n}}$ where $\seqRange{z_1}{z_n}$ are pairwise unique.
\end{definition}

\paragraph{Pure functions}

A value type $A$ that appears in a context where only a computation type is permitted is shorthand for the computation type $\tyComp{A}{}$.
